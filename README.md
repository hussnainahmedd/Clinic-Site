The public website for **Sadiq Medical & Gynae Clinic** — a warm, one-page site that tells walk-in patients exactly what they need to know: who treats them, what services are offered, where to find the clinic, and when it's open.

</div>

## ✨ Features

- **Hero with live hours badge** — Mon–Sat, 7:30 PM – 12:00 AM, plus a click-to-call button so patients can reach the clinic in one tap
- **Services section** — general physician care plus dedicated women's health consultations with Dr. Ayesha Rizwan (MBBS, MCPS)
- **Doctors profiles** — Dr. M. Rizwan Sadiq (general physician) and Dr. Ayesha Rizwan (gynae), with photos
- **Location & hours** — embedded Google Map of Scheme No. 2, Lahore, with an "Open in Google Maps" link for directions
- **Contact section** — phone-first contact for walk-in patients
- **Tribute section** — honoring Muhammad Sadiq, whose name and values the clinic carries
- **Scroll-reveal animations** — custom scroll-triggered reveal component for a smooth, polished feel
- **Fully responsive** — designed mobile-first, since most patients visit from their phones

## 🛠 Tech Stack

| Tech | Role |
|------|------|
| Next.js 16 (App Router) | Framework |
| React 19 | UI |
| TypeScript | Type safety |
| Tailwind CSS 4 | Styling |
| Lucide React | Icons |

Design-wise it's a warm editorial look — cream backgrounds, deep navy, and a calm teal accent, with a serif/sans type pairing.

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Other scripts:

```bash
npm run build   # production build
npm run start   # serve the production build
npm run lint    # run ESLint
```
